# Preprocesamiento-cienciadatos
## Descripción General:
Este repositorio contiene un conjunto de herramientas y scripts diseñados para realizar el preprocesamiento de datos, una etapa fundamental dentro de cualquier proyecto de Ciencia de Datos.
El objetivo principal es preparar los datos para su posterior análisis, modelado o visualización, aplicando técnicas como limpieza, normalización, detección de outliers y codificación de variables.
## Objetivo del Proyecto

- Implementar un flujo básico de preprocesamiento utilizando Python.

- Practicar el uso de Git y GitHub para control de versiones.

- Aplicar buenas prácticas de organización y documentación en un proyecto real.

- Integrar automatización usando GitHub Actions como parte del curso Cultura Digital y Sociedad.
